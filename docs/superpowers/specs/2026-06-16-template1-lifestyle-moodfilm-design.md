# Template 1 — 대비 라이프스타일 무드필름: 기획(포맷 바이블) + 자동화 설계

- **날짜:** 2026-06-16
- **상태:** 설계 승인 대기
- **브랜치:** `feature/template1-moodfilm`
- **범위:** 리빙시퀀스 유튜브 채널의 첫 영상 포맷("Template 1")의 **창작 기획(포맷 바이블)** + 이를 실행할 **자동 생성 로직의 아키텍처**. 다른 포맷(템플릿)은 각자 별도 기획·설계.

---

## 1. 배경 / 목적

리빙시퀀스 IR의 **S2 콘텐츠 자동화**의 실제 영상 포맷이다. 기존 인테리어 유튜브(예쁜 집 전시)와 차별화 — **"다양한 사람들의 라이프스타일을 감도(感度)로 보여주는" 무드필름**.

**자동화 목표 = "자동 크리에이티브 디렉터":**
> 스타일(+맥락) 입력 → 그 영상의 **기획**(어떤 대비·무드·shot 구성) + **감도 입힌 생성 프롬프트 전부**를 자동 산출 → AI 클립 생성 → 조립 → 영상.

이 문서가 곧 그 디렉터의 **규칙서**다. 사람이 읽는 글일 뿐 아니라, *"이 규칙대로면 프롬프트가 자동으로 나온다"* 수준으로 구체적이어야 한다.

**참조 자산:**
- 예시영상: `4e49b2b7-5e51-4076-a307-0242928ffc2b.mp4` (19.3s, 1920×1080, 60fps, BGM) — 구조·감도의 그라운드 트루스
- 감도 DNA 시드: `image_ui.html`의 `DNA_CODEBOOK`(10카드)
- 20스타일 taxonomy: `NEW` monorepo `packages/shared/src/taste-kit/v4-data.ts`(STYLE_IDS_V4) + `public.styles` DB(color_palette·materials·keywords)
- 배포: 본 `auto` 프로젝트(FastAPI+React, S2 PHASE 3)

## 2. 컨셉·메시지 (불변 · RAIL)

- **핵심:** 예쁜 집을 전시하는 게 아니라, **한 사람의 취향이 밴 "삶의 결"** 을 — 대비되는 바깥 맥락과 병치해 **감각으로 느끼게** 하는 ~20초 무드필름.
- **정서 메시지:** *"세상은 분주하고 똑같이 흐르지만, 당신의 취향이 만든 공간/삶은 오직 당신만의 것"* → **Find Your Taste** (나다운, 불안 없는 안식).
- **주인공 = 사람의 삶.** 인테리어는 그 삶을 통해 *느껴지는 배경*. 맥락은 그 삶에 *대비와 의미*를 주는 장치.

---

## 3. 구조 공식 (불변 · RAIL)

```
Phase A · 대비 빌드업 (0~13s)   [맥락 clip] ⊗ [사람 clip] 스플릿 페어 × 여러 쌍, 가속 컷
Phase B · 해소        (13~17s)  스플릿 풀림 → 사람이 자기 공간에서 맥락을 바라봄 (두 세계 융합)
Phase C · 브랜드      (17~20s)  Living Sequence + 로고 마크 + 스타일명
```
- **리듬:** 가속(빠른 컷) → 감속 → 정적
- **스펙:** ~20초 · 16:9 1920×1080 마스터 · BGM · 무내레이션 · 익명 인물
- **고정:** 모든 Template 1 영상이 이 arc를 공유 → 채널에서 "이 시리즈" 인식점. 변주는 *내용*에서, *구조*는 일정.

## 4. 변주 축 + 위임 경계 (RAIL vs LLM)

**영상마다 달라지는 입력 = 자동 디렉터의 다이얼:**

| 축 | 내용 | 결정 주체 |
|---|---|---|
| 1 · 스타일 (20) | 우측 "그 사람의 세계" | 입력값 → Layer B |
| 2 · 맥락 | 좌측 "대비 세계" (도시? 안개 낀 항구? 새벽 편의점?) | **LLM 창작** (열거 안 함) |
| 3 · 분위기 모듈레이터 | 계절·시간·날씨 (색온도·빛) | 입력값 or LLM |
| 4 · shot 선택·순서 | 모티프 조합 | LLM + 시스템 |

**핵심 원칙 — 레일은 고정, 콘텐츠는 LLM:**

```
고정 (RAILS, LLM 안 맡김)          위임 (CONTENT, LLM 매 영상 창작)
· 컨셉·메시지                       · 맥락 (무엇과 대비할지)
· 구조 공식 (Phase A/B/C)           · shot 구성·순서
· 감도 DNA Layer A                  · 무드 디테일 (스타일 안에서)
· 20 스타일 taxonomy                · 맥락 shot ↔ 사람 shot 페어링
· 출력 스펙
```

맥락 테마를 4개로 못박지 않는다. LLM에게 *"이 컨셉·이 감도로, 이 스타일의 사람을 대비시킬 맥락과 shot을 짜라"* 고 시킨다. **단, 위임은 빡센 레일 안에서만** (§5·§9 안전장치).

## 5. 감도 규칙 — 2 레이어 (RAIL의 심장)

감도는 한 겹이 아니다. **불변 브랜드 시그니처(A)** 와 **스타일별 가변(B)** 로 분리한다.

### Layer A · 불변 감도 (모든 영상·모든 스타일 · 프롬프트에 강제 주입)
- 모션블러 / 흐름감 (정확한 포착 X, 흐름 O)
- 익명 인물 (얼굴 안 보임 — 뒷모습·실루엣·잘림)
- 단일 부드러운 광원 · 자연광 · 플래시/HDR 없음 (빛의 *성질*만 고정)
- 관찰자 거리 · 네거티브 스페이스 · 오프센터
- 35mm 필름그레인 · 부드러운 대비 · 디지털 샤프 없음
- "전환의 순간"(정점 아님) · 일상 오브제가 주인공
- 에디토리얼 격조 (Cereal/Kinfolk 톤)
- 무내레이션 + BGM

### Layer B · 가변 감도 (20스타일이 결정 · `public.styles` DB 조회)
- `color_palette` (웜모던=앰버 / 인더스트리얼=차콜 / 화이트미니멀=백색…)
- `materials` (오크·브라스 / 콘크리트·철 / …)
- 인물 의상 (스타일별 wardrobe)
- 공간 미감 (미니멀 / 럭셔리 / 러프…)

> **근거:** 옛 `image_ui` DNA는 색·소재까지 전역 고정("warm amber 모두에게")이라 20스타일과 충돌했다. 빛의 성질·카메라언어·필름질감·익명성은 고정(A), 색·소재·의상은 스타일이 결정(B)으로 쪼개면 20스타일이 다 다르게 보이면서도 전부 "Living Sequence"로 읽힌다. (길다.txt의 2-레이어 모델 = Layer 1 변하는 것 / Layer 2 불변.) **예시영상이 이를 증명:** 모션블러·익명·필름그레인 = A, 앰버 = B(웜 스타일), 차가운 겨울도시 = 맥락(LLM).

## 6. 프롬프트 조립 공식 (자동 디렉터의 출력 단위)

각 shot의 최종 생성 프롬프트는 세 조각의 합:

```
shot 프롬프트 = [Layer A 감도 · 항상 고정]
              + [Layer B · 스타일 DB 조회]
              + [LLM 창작 · 이 shot의 맥락/장면/무드]
```

영상 1편 흐름: **LLM이 (맥락 + shot 리스트[역할·페어링] + 무드)를 기획 → 각 shot에 위 공식으로 프롬프트 조립 → 클립 생성 → 조립.**

**예시 (industrial × 자연 · 사람측 1 shot):**
```
[A·고정]   subtle motion blur, anonymous figure turned away, single soft window
           light, negative space, 35mm film grain, transitional moment, editorial
           quietness, no narration
[B·industrial DB]  charcoal & rust palette, exposed concrete + blackened steel +
           aged leather, weathered tactile surfaces, muted desaturation
[LLM·shot] a hand resting on a raw concrete wall beside a black steel shelf holding
           a single whiskey glass, late autumn afternoon haze
```

## 7. 브랜드 · CTA 연결

- **인필름(영상 안):** 브랜드 아웃트로만 — `Living Sequence + 로고` + **스타일명 한 줄**(예: "Warm Modern"). 절제.
- **전환은 영상 밖:** 설명란·고정댓글·엔드스크린에 *"당신의 취향은? → 취향 Kit"* 링크.
- **소프트 미끼:** 영상이 *스타일을 보여줌* → "이게 내 취향인가?" → Kit. **스타일 라벨링 자체가 전환 훅.** 무드필름은 순수하게, 20초 안에 "구독하세요" 외치지 않음.

## 8. 예시 컨셉 3개 (기획 검증)

같은 공식이 스타일·맥락·분위기만 바뀌어 완전히 다른 영상을 내는지 확인:

| | 스타일(B) | 맥락(LLM) | 분위기 | 한 줄 컨셉 |
|---|---|---|---|---|
| ① | warm_modern | 도시 | 겨울·밤 | 분주한 눈 도시 ↔ 황동빛 나만의 안식 *(≈예시영상)* |
| ② | industrial | 자연 | 가을·안개 | 안개 낀 가을 숲의 광활 ↔ 거친 콘크리트 속 고요 |
| ③ | biophilic | 군중 | 여름·낮 | 횡단보도 인파 ↔ 식물로 숨 쉬는 나만의 온실 |

①은 앰버+오크, ②는 차콜+콘크리트, ③은 그린+식물이 Layer B에 꽂혀 — 같은 레일에서 다른 영상. **기획이 작동한다.**

## 9. 자동화 아키텍처 (high-level · 상세는 implementation plan에서)

```
⓪ 페르소나 캐스팅 (AI)      대량 페르소나 후보 → "좋은 영상 될까?" 판단·선별 → 소진된 것 제외
   │                        (선택된 1 페르소나 = style + 삶의 설정 = 이 영상의 주인공)
   ▼
① 자동 디렉터 (LLM)         포맷 바이블 + 선택 페르소나 → 이 영상의 기획 산출(구조화 JSON):
                            맥락 테마, shot 리스트(역할·페어), 무드, 분위기
   │
   ▼
② 프롬프트 조립             각 shot = Layer A(고정) + Layer B(스타일 DB 조회) + LLM shot설명
   │
   ▼
③ 클립 생성 + 라이브러리     image(nano_banana/soul) → video(kling/seedance, start_image) via Higgsfield.
                            "맞는 라이브러리 클립 있으면 재사용, 없으면 생성 후 적재" → 라이브러리 유기적 성장
   │
   ▼
④ 조립 엔진 (FFmpeg)        스플릿 페어링(A) + 해소(B) + 브랜드 아웃트로(C) + BGM → 16:9 마스터
   │
   ▼
⑤ auto 배포                draft 저장 → 9:16 등 크롭 → 7채널 예약·배포 (기존 auto 활용)
```

### ⓪ 페르소나 캐스팅 — AI 선별 + 소진 (큐레이션 레이어)

- **대량 후보 생성:** 스타일(20) × 삶의 설정(직업·생활리듬·공간상황) × 계절 등 → 방대한 페르소나 풀. (1 페르소나 = 영상 1편의 주인공.)
- **AI 선별("잘 뽑힐만한"):** 각 후보를 점수화 → 상위만 제작. 기준 = ①감도 잠재력 ②맥락 대비 강도 ③차별성(기존·최근과 안 겹침) ④스타일 밸런스(대중↔니치) ⑤유튜브 훅 잠재력.
- **소진 추적:** 제작된 페르소나는 `used` 마킹(DB) → 재선택 영구 제외. (story_ui `usedIds`의 영속·AI버전.) 같은 사람으로 두 번 안 만든다.
- **데이터 플라이휠 연계:** 향후 취향 Kit 결과 분포·영상 성과를 선별 기준에 피드백 → 잘 되는 페르소나 방향으로 캐스팅 학습.

**안전장치 (위임의 리스크 대응):**
1. **감도 DNA(Layer A) 강제 주입** — LLM 자유와 무관하게 매 프롬프트에 박힘 → 브랜드 드리프트 방지.
2. **후보 N개 생성 + 거르기** — LLM 기획/클립을 복수 생성 → 점수 또는 사람 승인(IR의 "검수·승인" 단계).
3. **라이브러리 성장 모델** — 창의성(매번 새 기획) ↔ 비용(재사용)을 양립: 재사용 우선, 없을 때만 생성.

**컴포넌트 경계 (각자 독립 테스트 가능):**
- ⓪ 페르소나 캐스팅(AI 선별+소진) — 페르소나 풀 → 선택 1 페르소나. 점수·중복 로직 독립 테스트.
- ① 자동 디렉터(LLM 기획) + ② 프롬프트 조립 — 입력 페르소나 → 출력 프롬프트 셋(JSON). 클립 없이 테스트 가능.
- ③ 클립 생성 + 라이브러리 — 프롬프트 → 클립(+메타데이터). 
- ④ 조립 엔진 — 클립 셋 → 16:9 영상.
- ⑤ auto 배포 — 기존.

`auto` 백엔드의 `app/services/`에 신규 서비스로 얹는다(예: `app/services/template1/`).

## 10. 출력 스펙

16:9 1920×1080 마스터 · ~20초 · H.264 mp4 · BGM 트랙 · 무내레이션 · 브랜드 아웃트로. 9:16(숏폼) 등 채널별 파생은 ⑤에서 크롭.

## 11. 결정 사항 (브레인스토밍에서 승인 완료)

1. 컨셉 = "대비를 통한 취향의 안식", 예쁜 집 전시 아님.
2. 구조 = Phase A 대비 → B 해소 → C 브랜드, **고정**.
3. 변주 = **레일 고정 + 맥락·shot·무드는 LLM 위임** (맥락 테마 열거 안 함).
4. 감도 = **2 레이어** (A 불변 / B 스타일 DB).
5. 클립 = **라이브러리 재조합 기반**, 단 LLM 창작으로 라이브러리 유기적 성장.
6. 출력 = 16:9 ~20초 BGM 무내레이션.
7. **페르소나 캐스팅** = 대량 후보 중 **AI가 "잘 될 영상" 선별** + 제작된 건 **소진(재사용 영구 금지)**.

## 12. 비목표 / 범위

- 다른 템플릿(포맷)들 — 별도 기획·설계.
- 실제 7채널 업로드 OAuth — `auto` 배포에 위임 / 후속.
- BGM 자동 작곡 — 1차는 큐레이션 라이브러리(스타일·무드별).
- 완전 무인 자동발행 — 1차는 사람 승인 게이트 유지.

## 13. 미해결 / 후속 결정 (implementation plan에서 확정)

- 자동 디렉터 LLM 선택 (Claude vs Gemini) + 기획 산출 JSON 스키마.
- 클립 생성 모델 확정 (Higgsfield kling3_0 / seedance_2_0) + 비용·시간.
- 라이브러리 스키마·태깅(스타일/맥락/모티프/역할/길이)·매칭 로직.
